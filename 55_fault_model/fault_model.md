# 矩形断層モデル 3Dビューア 説明書

## 1. 概要

本ドキュメントは、HTMLファイル（`fault_model.html`）で実装した
**矩形断層モデル 3Dビューア** の仕様・使い方・座標系・計算方法を説明するものです。

このビューアは、断層の中心を原点として、以下の7つのパラメータで記述される
矩形断層（有限断層モデル）を3Dで可視化します。

- 断層の中心（原点）
- 走向（Strike）
- 傾斜（Dip）
- すべり角（Rake）
- 長さ（Length）
- 幅（Width）
- 上端深さ（Top Depth）

ブラウザでHTMLを開くだけで動作し、追加のインストールは不要です。

## 5. 座標系の定義

本ビューアでは以下の座標系を採用しています。

- **北** ＝ -Z 方向
- **東** ＝ +X 方向
- **上** ＝ +Y 方向（深さは -Y で表される）

### 角度の定義

- **走向（Strike）**：北を0°とし、時計回りに測った角度。
  - 0°＝北、90°＝東、180°＝南、270°＝西
- **傾斜（Dip）**：水平面からの下向きの角度。0°＝水平、90°＝垂直。
- **すべり角（Rake）**：走向方向を0°とし、断層面上で測った滑り方向の角度。
  - 0°／180°前後：横ずれ断層
  - 90°前後：逆断層（上盤が乗り上げる）
  - -90°前後：正断層（上盤が落ち込む）
