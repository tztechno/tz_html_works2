# ペアローン返済シミュレーター — 使用マニュアル

夫婦でペアローンを組んだときに、完済まで家計がもつかを年単位で試算するツールです。金利の上昇、収入の減少、産休・育休、介護離職などの条件を変えて、貯金が底をつく時期を確認できます。

インストールは不要で、すべてブラウザ内で計算します。入力した内容が外部に送信されることはありません。

---

## 1. はじめ方

1. 次のどちらかで開きます。
   - 公開ページ: https://tztechno.github.io/tz_html_works2/54_pairloan/
   - ダウンロードした場合: `index.html` をダブルクリック（Webサーバーは不要）
2. 左のパネルに自分の条件を入力します。入力するとすぐに再計算されます。
3. 右のパネルで判定と年ごとの内訳を確認します。
4. 残しておきたい結果は「CSVダウンロード」で保存します。

入力内容は保存されません。ページを再読み込みすると初期値に戻るので、必要な結果はCSVで保存してください。

---

## 2. 入力項目

金額の単位は項目ごとに異なります。**借入額だけ「万円」、それ以外は「円」** です。収入はボーナスを含めて月額にならした手取り額を入力します。

### ローン条件

| 項目 | 初期値 | 説明 |
|---|---|---|
| 借入額（総額・万円） | 5000 | 夫婦の借入額の合計 |
| 返済期間（年） | 35 | 元利均等返済として計算 |
| 現在の金利（%） | 1.0 | 1年目の金利。夫婦とも同じ金利として計算 |
| 金利タイプ | 変動金利 | 全期間固定か変動金利か（§4.1） |
| 金利変動シナリオ | 上昇 | 変動金利の場合の金利の動き（§4.2）。全期間固定では無視される |
| 妻の返済負担割合（%） | 40 | 返済額の夫婦への配分（§4.3） |

### 住宅関連費（月額）

| 項目 | 初期値 | 説明 |
|---|---|---|
| 管理費（円） | 15000 | 毎月の管理費 |
| 管理費 年間上昇率（%） | 1.5 | 毎年この割合で上昇 |
| 駐車場代（円） | 10000 | 毎月の駐車場代 |
| 駐車場 年間上昇率（%） | 1.0 | 毎年この割合で上昇 |
| 修繕積立金（円） | 12000 | 毎月の修繕積立金 |
| 修繕積立 年間上昇率（%） | 2.0 | 毎年この割合で上昇 |
| 段階値上げ（何年ごと） | 5 | 年間上昇とは別に値上げする間隔。0なら段階値上げなし |
| 段階値上げ率（%/回） | 10 | 1回あたりの値上げ率 |

### 収入（夫）

| 項目 | 初期値 | 説明 |
|---|---|---|
| 現在の月収（手取り・円） | 380000 | 1年目の月収 |
| 昇給率（%/年） | 0.5 | マイナスも入力可 |
| 収入減少イベント | 恒久的減少 | なし／一時的減少（3年で回復）／恒久的減少 |
| 減少開始（年後） | 10 | 10なら11年目から減少 |
| 減少率（%） | 20 | 収入を減らす割合 |

### 収入（妻）

| 項目 | 初期値 | 説明 |
|---|---|---|
| 現在の月収（手取り・円） | 250000 | 1年目の月収 |
| 昇給率（%/年） | 0.5 | マイナスも入力可 |
| 産休・育休イベント | 1回 | なし／1回／2回。いずれも1回あたり1年間。2回の場合、2回目は1回目の2年後 |
| 休業開始（年後） | 3 | 3なら4年目が休業 |
| 休業中の収入率（%） | 50 | 休業中に受け取る収入の割合 |
| 介護離職イベント | なし | なし／1年休業／完全離職。該当期間の収入は0円 |
| 介護開始（年後） | 15 | 15なら16年目から |

### その他生活費

| 項目 | 初期値 | 説明 |
|---|---|---|
| 基本生活費（月・円） | 180000 | 住宅関連費と教育費を除く生活費 |
| 子供の人数 | 1 | 第1子は開始時点で0歳、以降は2歳差として計算 |
| 子供1人あたり教育費（月・円・平均） | 30000 | 年齢に応じた係数を掛けて計算（§4.5） |
| 物価上昇率（%/年） | 1.0 | 基本生活費と教育費の両方に適用 |
| 現在の預貯金（円） | 3000000 | シミュレーション開始時の貯金 |

### 不足時の一時金

親からの援助や保険の解約など、貯金が足りないときに入れるまとまったお金を想定した設定です（§4.6）。

| 項目 | 初期値 | 説明 |
|---|---|---|
| 一時金モード | なし | なし（破綻判定）／不足分を自動補填／指定額を補填 |
| 一時金額（円） | 1000000 | 「指定額を補填」での1回あたりの上限額 |
| 一時金 開始（年後） | 10 | 「指定額を補填」で、この年より前は補填しない |
| 一時金 上限回数 | 3 | 補填できる回数。**0を入力すると無制限** |

## 3. 結果の見方

### 判定

| 表示 | 意味 |
|---|---|
| ✅ 完済まで破綻しません | 完済でき、貯金も常に100万円以上ある |
| ⚠️ 返済は可能だが貯金がほぼ底をつく | 破綻はしないが、貯金が100万円を下回る年がある |
| ⚠️ 破綻はしないが満期に残債○万円の一括返済が必要 | 満期に返しきれない分が残るが、貯金で精算できる（§4.1） |
| ❌ ○年目（○年後）に破綻 | 貯金が初めてマイナスになった年。一時金を入れてもマイナスの場合を含む |

一時金モードが「なし」以外のときは、実際に使ったかどうかにかかわらず判定の末尾に「（一時金による補填を前提）」が付きます。

### サマリー

| 項目 | 説明 |
|---|---|
| 初年度 月返済／夫の月返済／妻の月返済 | 1年目の毎月の返済額と、夫婦それぞれの負担額 |
| 夫・妻 最大返済比率 | 全期間で最も高かった「本人の返済額 ÷ 本人の手取り収入」。返済があるのに収入が0円の年があれば「収入ゼロ期間あり」と表示 |
| 満期時 残債 | 満期に返しきれなかった額。最終年に貯金から一括返済する |
| 初年度 住宅関連費計 | 1年目のローン返済、管理費、駐車場代、修繕積立金の月額合計 |
| 最悪月収支 | 全期間で最も低かった毎月の収支 |
| 最低貯金残高／最終貯金残高 | 全期間の年末貯金の最低額と、最終年の年末貯金 |
| 完済時 月返済 | 最終年の毎月の返済額 |
| 一時金 使用回数／合計 | 実際に補填した回数と金額の合計 |

### 年次テーブル

1年ごとに1行です。破綻した年の行は赤く表示されます。**単位は列によって異なります。**

| 列 | 単位 | 説明 |
|---|---|---|
| 年 | — | 何年目か |
| 金利% | % | その年の金利 |
| ローン返済／夫返済／妻返済 | 円/月 | 毎月の返済額と夫婦の内訳 |
| 年末残高 | 万円 | 年末のローン残高。最終年の値は一括返済前の残債 |
| 管理費／駐車場／修繕 | 円/月 | 各費用の月額 |
| 住宅計 | 円/月 | ローン返済と上の3費用の合計 |
| 生活費 | 円/月 | 基本生活費と教育費の合計 |
| 夫収入／妻収入／収入計 | 円/月 | 手取りの月額 |
| 収支 | 円/月 | 収入計 −（住宅計 + 生活費） |
| 一時金 | 円 | その年に補填した額。なければ「-」 |
| 貯金残高 | 万円 | 年末の貯金。最終年は残債の一括返済後 |

## 4. 計算のルール

計算は1年単位です。毎年「収支 × 12か月」を貯金に加え、その結果で判定します。そのため、年の途中で一時的に貯金が足りなくなる場合は判定に現れません。

### 4.1 返済額の計算

- **全期間固定:** 返済額は最後まで同じです。
- **変動金利:** 次のルールで計算します。
  - **5年ルール:** 返済額は5年ごとに見直します。見直しまでの間に金利が変わっても返済額は変わらず、元金と利息の内訳だけが変わります。
  - **125%ルール:** 見直し後の返済額は、直前の返済額の1.25倍までです。
- **満期の残債:** 上のルールにより、満期に返しきれない分が残ることがあります。残った分は最終年に貯金から一括返済します。

### 4.2 金利変動シナリオ

| シナリオ | 金利の動き |
|---|---|
| 一定 | 変わらない |
| 上昇 | 毎年+0.25%。上限3% |
| 乱高下 | 約±0.5%の波で上下し、5年ごとに+0.2%上乗せ。下限0.3% |
| 下落 | 毎年−0.1%。下限0.3% |
| 段階的上昇 | 5年ごとに+0.2%。上限3% |

現在の金利がすでに3%を超えている場合、「上昇」と「段階的上昇」では現在の金利のまま変わりません。

### 4.3 妻の返済負担割合

割合に応じて毎月の返済額を夫婦に配分し、それぞれの返済額と返済比率を計算します。**世帯の返済総額は変わらないので、割合を変えても判定と貯金残高は変わりません。** 片方の収入が減ったときに、本人の負担が重くなりすぎないかを確認するために使います。

### 4.4 収入

昇給は毎年複利で反映され、イベントの間も続きます。たとえば恒久的減少では、昇給後の収入に（1 − 減少率）を掛けます。

### 4.5 教育費

子供1人あたりの月額は「教育費 × 年齢の係数」です。これに基本生活費を足し、物価上昇率を掛けたものが生活費になります。

| 子供の年齢 | 係数 |
|---|---|
| 0〜5歳 | 0.5 |
| 6〜11歳 | 0.7 |
| 12〜14歳 | 1.0 |
| 15〜17歳 | 1.6 |
| 18〜21歳 | 3.0 |
| 22歳以降 | 0 |

### 4.6 一時金

年末の貯金がマイナスになったときだけ補填します。余分な額は入りません。

- **不足分を自動補填:** 不足額をそのまま補填します。一時金額と開始年は使いません。
- **指定額を補填:** 開始年以降、「一時金額」と不足額の少ないほうを補填します。一時金額では足りない年は破綻と判定されます。
- **共通:** 上限回数に達すると補填されなくなり、その後に貯金がマイナスになると破綻と判定されます。

## 5. CSVの保存

「CSVダウンロード」を押すと、`pairloan_simulation_年月日_時分秒.csv` という名前で現在の結果を保存します。Excelで開いても文字化けしない形式（BOM付きUTF-8）です。

| 内容 | 説明 |
|---|---|
| 結果の概要 | 出力日時、判定、一時金の回数と合計、満期時の残債 |
| 設定パラメータ | 入力したすべての項目 |
| 年次シミュレーション | 年ごとの内訳。金額はすべて円単位で、一時金を入れる前の貯金も含む |

CSVの判定欄は「破綻あり／なし」だけを示します。貯金が少ない場合の警告は含まれないので、残債は「満期時 残債」の行で確認してください。

## 6. 使い方の例

- **金利上昇への耐性を見る:** 金利タイプを「変動金利」にして、シナリオを切り替えて比べます。全期間固定と比べると、最終貯金残高の差が分かります。
- **収入が減った場合を見る:** 夫の「恒久的減少」や妻の「完全離職」を選び、開始年を変えて破綻する時期を確認します。
- **必要な援助額を見積もる:** 一時金モードを「不足分を自動補填」、上限回数を0にすると、「一時金 合計」が破綻を避けるために必要な総額の目安になります。
- **負担割合を決める:** 妻の負担割合を変えながら、休業や離職を入れたときの「最大返済比率」を比べます。

---

## 7. 注意事項

このツールは計画の目安を出すためのもので、実際の返済額や将来の家計を保証するものではありません。契約内容は金融機関に確認してください。

次の項目は計算に含まれません。

- 住宅ローン控除、固定資産税、火災保険、団体信用生命保険
- 借入時の諸費用、繰上返済、借り換え
- 貯金の運用益
- 夫婦で異なる金利や返済期間（ペアローンの2本は同じ条件として計算）
- 銀行によって異なる取り扱い（5年ルールや125%ルールがない商品もあります）
