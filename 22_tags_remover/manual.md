# Tags Remover 操作マニュアル

貼り付けたテキストから改行・タブ・余分なスペースを取り除くための、ブラウザだけで動くツールです。サーバーには何も送信されず、すべての処理はその場（ブラウザ内）で完結します。

## 画面構成

画面上部に **Convert**（変換）と **Options**（設定）の2つのタブがあります。

- **Convert タブ**：テキストの入力・変換結果の確認・コピーを行う画面です。開いたときはこちらが表示されます。
- **Options タブ**：どの種類の空白を取り除くかを選ぶ画面です。タブのラベルには「5/5」のように、現在オンになっている設定の数が表示されます。

## 使い方（Convert タブ）

1. 上部の **Remove whitespace** ボタンのすぐ下に、**Input**（入力）と **Result**（結果）の2つの枠があります。
2. **Input** 欄に処理したいテキストを貼り付けます。
3. 入力すると同時に **Result** 欄が自動的に更新されます（ライブ更新）。**Remove whitespace** ボタンを押しても同じ結果が得られますが、通常は押さなくても構いません。
4. 各欄の右上には文字数が表示され、Result 側には「何文字減ったか」も表示されます。
5. **Result** 欄下の **Copy** ボタンで、変換結果をクリップボードにコピーできます。
6. **Input** 欄下の **Clear** ボタンで、入力内容を消去できます。

初回表示時は、動作を確認しやすいようにサンプルテキストがあらかじめ入力されています。

## 設定項目（Options タブ）

Options タブでは、以下の5つの処理を個別にオン・オフできます。オンになっている項目は緑色でハイライトされます。設定の変更は即座に反映され、Convert タブに戻ると結果に反映されています。

| 項目 | 内容 |
|---|---|
| Newlines（¶） | 改行（`\n`）を削除します |
| Tabs（⇥） | タブ文字（`\t`）を削除します |
| Multiple → single space（␣²） | 連続する半角スペースを1つにまとめます |
| Lead/Trail spaces（⎵） | 文章の先頭・末尾の余分なスペースを削除します |
| All spaces（␣） | すべての半角スペースを削除します |

初期状態ではすべてオンになっています。「単語の間隔は保ちたいが連続スペースだけ整えたい」といった場合は、**All spaces** をオフにして **Multiple → single space** だけを使うと自然な仕上がりになります。

### 処理の適用順序

複数の設定を同時にオンにした場合、内部では次の順序で処理されます。

1. 改行を削除（Newlines）
2. タブを削除（Tabs）
3. 連続スペースを1つに（Multiple → single space）
4. 先頭・末尾のスペースを削除（Lead/Trail spaces）
5. すべてのスペースを削除（All spaces）

**All spaces** がオンの場合、他の設定の効果は最終的にすべて上書きされる（＝空白がすべて消える）点に注意してください。

## スマートフォンでの表示について

画面幅が狭い場合は、レイアウトが自動的に調整されます。

- 実行ボタンは入力欄より上に固定表示され、スクロールしなくても押せます。
- 入力・結果欄は高さを抑えてあり、それぞれの枠内だけでスクロールします（ページ全体は基本的にスクロール不要です）。
- Options タブの設定項目は、タップしやすいカード形式で表示されます。

## その他

- ダーク／ライトモードは、お使いの端末・ブラウザの設定に自動で追従します。
- 入力したテキストはブラウザ内だけで処理され、外部には一切送信されません。
