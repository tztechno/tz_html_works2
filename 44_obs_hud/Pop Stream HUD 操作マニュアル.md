# Pop Stream HUD 操作マニュアル

2026-09-17 · @Someone

## 概要

Pop Stream HUDは、OBSのブラウザソースに読み込んで使う配信用オーバーレイです。ロゴ、時計、配信開始からの経過タイマー、ステータス表示、進捗バー、タイトル用のテロップ枠を1画面にまとめてあり、ポップでカラフルな配色を設定パネルから選べます。

ページの背景は常に透過されるため、ゲーム画面やカメラ映像の上に重ねて配信できます。

## 基本的な使い方

ページを開くと、初回訪問時のみ自動で設定パネルが開きます。ここでタイトルや配色などを一通り調整してから使い始めるのがおすすめです。

2回目以降は自動では開きません。手動で開閉するには以下のいずれかを使います。

- 画面右下の歯車アイコン（⚙）をクリック
- キーボードの `S` キーを押す（入力欄にフォーカスがない状態で）

設定パネルで変更した内容は自動保存され、同じブラウザで次回開いたときも引き継がれます。

## 設定パネルの項目

| セクション | 項目 | 内容 |
| --- | --- | --- |
| テロップ / タイトル | タイトル・サブタイトル | 画面下部のバーに表示する文字。チェックを外すとバーごと非表示にできます |
| ロゴ / ウォーターマーク | ロゴテキスト | 左上のバッジに表示する名前やチャンネル名 20文字まで |
| 時計 / 経過タイマー | 現在時刻・経過タイマー | それぞれ個別にON/OFF。「タイマーをリセット」で配信開始時刻に戻せます |
| ステータス / 進捗 | ステータス文言・カラー | LIVE（赤）・GAME（紫）・CODING（緑）・BREAK（黄）から選択、またはテーマのアクセント色に合わせる |
| ステータス / 進捗 | 進捗ラベル・進捗% | 0～100の数値。空欄のままにすると進捗バーは非表示 |
| デザイン | 配色プリセット | Neon / Citrus / Candy / Retro の4種から選択。全パーツのグラデーションに一括適用 |
| デザイン | 全体スケール | 0.6〜1.6倍。OBSのキャンバスサイズに合わせて文字・バッジ全体の大きさを一括調整 |

変更は即時プレビューに反映されます。

## OBSへの反映方法

1. 設定パネル下部の「OBS用URLをコピー」をクリックする（現在の設定を反映したクリーン用URLがクリップボードにコピーされます）
2. OBSで「ソース」の＋ボタン→「ブラウザ」を選択して新規作成
3. URL欄にコピーしたURLを貼り付け
4. 幅・高さを設定（推奨: 1920×1080、小さめのオーバーレイにする場合はフルスクリーンを基準に幅・高さを小さくしてもOK）
5. 「シーンが表示されていないときにソースをシャットダウン」は **OFF** にする（ONのままだとタブ切り換えで経過タイマーが止まります）

このコピーURLは末尾に `clean=1` が付く仕組みになっており、OBS上では設定パネルや透過プレビュー用のチェック柄背景などの編集UIは一切表示されず、背景は自動で透過します。

## 便利な機能

- **プレビュー**: 「この見た目をプレビc��ー（OBS表示を確認）」を押すと、実際にOBSで表示される状態（設定パネル・チェック柄背景なし）をその場で確認できます。`Esc` キーまたは画面上部の「編集モードに戻る」で解除
- **経過タイマーの永続化**: タイマーの開始時刻はブラウザ（OBSの内部ブラウザも含む）に保存されます。OBSがソースを再読み込みしてもタイマーはリセットされず、配信開始からの経過時間を正確に表示し続けます
- **タイマーのリセット**: 設定パネルの「タイマーをリセット」で現在時刻に戻ります（新しい配信を始めるときなど）
- **キーボードショートカット**: `S` = 設定パネルの開閉、`Esc` = パネルを閉じる/プレビューを終了

## トラブルシューティング

| 症状 | 対処 |
| --- | --- |
| 背景が透過されず黒や白で表示される | コピーしたURLに `clean=1` が含まれているか確認�扅入力したURLを使っている場合は「OBS用URLをコピー」から取り直す |
| タイマーが意図せず0に戻る | ブラウザ（OBS内部ブラウザ）の保存データがクリアされた可能性。ブラウザベートドウィンドウやキャッシュ削除機能を使っていなぁ確認 |
| タイトルやステータスの文字が横に切れる | 文字数が長すぎる可能性。タイトルは短めにするか、設定パネルの「全体スケール」を下げる |
| OBS上で文字が小さすぎる/大きすぎる | ソースの幅・高さと「全体スケール」を合わせて調整（目安: 1920×1080でスケール1.0） |
| 設定が次回起動時に消えている | コピーしたURLをOBSのソースに保存したすべての設定はURL自体に含まれるので、URLを変えてしまうと内容もリセットされる。変更したら必ずコピーボタンでURLを取り直してOBSに貼り直す |
