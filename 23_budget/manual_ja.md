# 家計簿アプリ 使用マニュアル

対象ファイル: `kakeibo_app.html`

CSVファイルをデータベースとして使う、ブラウザだけで完結する家計簿アプリです。サーバーやインストール作業は不要で、ファイルをダブルクリックするだけで使えます。

## 1. 起動方法

`kakeibo_app.html` をダブルクリックすると、既定のブラウザで開きます。初回はサンプルデータが表示されます。

推奨ブラウザ: Google Chrome または Microsoft Edge（最新版）。Safari / Firefox でも一覧表示・追加編集削除・CSVの読み込み/保存は問題なく使えますが、「同じファイルに上書き保存」機能のみ Chrome 系ブラウザ限定です（4-3節参照）。

## 2. 画面構成

- **取引一覧**: 登録済みの収入・支出が表形式で並びます。列見出しをクリックすると並び替えができます。
- **フィルタ**: 種別（収入/支出）、カテゴリ、期間（開始日〜終了日）、メモのキーワード検索で絞り込めます。
- **サマリー**: 現在表示中のデータに対する収入合計・支出合計・収支を表示します。
- **グラフ**: カテゴリ別支出（表示範囲内）と、月別の収入・支出の推移を表示します。

## 3. 基本操作

### 3-1. 新規登録

「＋ 新規登録」ボタンを押し、日付・種別（収入/支出）・カテゴリ・金額・メモを入力して「保存」を押します。

### 3-2. 編集・削除

一覧の各行にある「編集」「削除」ボタンから操作します。削除時は確認ダイアログが出ます。

### 3-3. 検索・フィルタ・並び替え

フィルタ欄に条件を入力すると即座に一覧が絞り込まれます。列見出し（日付・種別・カテゴリ・金額・メモ）をクリックすると、その列で昇順/降順に並び替わります（もう一度クリックすると逆順）。

## 4. データの保存・永続化

このアプリには3種類の保存の仕組みがあります。それぞれ役割が異なるため、理解しておくと安心です。

### 4-1. 自動保存（ブラウザのlocalStorage）

取引を追加・編集・削除するたびに、内容は自動的にブラウザの保存領域（localStorage）に記録されます。次に**同じファイルを同じブラウザで**開いたときは、このデータが復元され、サンプルデータには戻りません。

ただし以下の場合は自動保存されたデータが読み込まれず、サンプルデータで開始します。

- 別のブラウザで開いた場合
- シークレット/プライベートウィンドウで開いた場合
- ブラウザの閲覧データ・サイトデータを削除した場合
- ファイルの別コピー（別バージョンや別の保存場所のファイル）を開いた場合

自動保存はあくまで「うっかり閉じても消えないための補助」であり、正式なバックアップではありません。重要なデータは次項のCSV保存で残してください。

### 4-2. CSVとして保存（エクスポート）

「CSVとして保存」を押すと、現在の全データが `budget_YYYY-MM-DD.csv`（日本語版では `kakeibo_YYYY-MM-DD.csv`）としてダウンロードされます。作業の区切りごとにこれを行っておくと、ブラウザの状態に関係なく確実にデータを残せます。

### 4-3. CSVを開く（インポート）／同じファイルに上書き保存

「CSVを開く」から既存のCSVファイルを読み込むと、現在のデータが読み込んだ内容に置き換わります。

Chrome系ブラウザでは、CSVを開いた後に「同じファイルに上書き保存」ボタンが有効になり、ダウンロードフォルダを経由せず、元のファイルへ直接上書きできます（File System Access APIという機能を使用）。この機能はSafari/Firefoxでは表示されません。

### 4-4. サンプルに戻す

現在のデータを破棄し、最初のサンプルデータに戻します。実行前に確認ダイアログが出ます。取り消しはできないため、必要なデータは先にCSV保存してください。

## 5. CSVファイルの形式

| 列名 | 内容 | 例 |
|---|---|---|
| date | 日付（YYYY-MM-DD形式） | 2026-09-04 |
| type | 種別（`income` または `expense`） | expense |
| category | カテゴリ名（自由記述可） | 食費 |
| amount | 金額（数値のみ） | 6800 |
| memo | メモ（任意、カンマや改行を含む場合は自動でダブルクォートで囲まれます） | スーパー |

1行目はヘッダー行（`date,type,category,amount,memo`）である必要があります。Excelで開いた際に日本語が文字化けしないよう、保存時にBOM付きUTF-8で出力しています。

## 6. 標準カテゴリ

- **収入**: 給与 / 副業 / 賞与 / 利子・配当 / その他収入
- **支出**: 食費 / 日用品 / 交通費 / 住居費 / 光熱費 / 通信費 / 娯楽 / 医療 / 衣服 / 教育 / その他支出

カテゴリ一覧に無いカテゴリ名をCSVに含めて読み込むこともできますが、その場合は登録・編集フォームのプルダウンには表示されません（一覧・フィルタ・グラフでは問題なく扱われます）。

## 7. トラブルシューティング

- **データが急にサンプルに戻った** → 4-1節を参照。別ブラウザ／シークレットモード／サイトデータ削除が原因である可能性が高いです。直前にエクスポートしたCSVがあれば「CSVを開く」で復元できます。
- **CSVをExcelで開くと文字化けする** → 本アプリが出力するCSVはBOM付きUTF-8のため、通常のExcelでは問題なく開けます。文字化けする場合は、Excelのインポート機能で文字コードをUTF-8に指定して読み込んでください。
- **「同じファイルに上書き保存」ボタンが出ない** → Safari／Firefoxなど、File System Access APIに対応していないブラウザでは表示されません。「CSVとして保存」でのダウンロードをご利用ください。
