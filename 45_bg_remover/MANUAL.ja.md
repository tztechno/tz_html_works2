# 背景除去ツール 使用マニュアル(日本語)

画像の背景をAIで自動除去し、透明PNGとして保存するWebアプリです。除去しきれなかった部分は消しゴムで手直しできます。

English version: [MANUAL.en.md](MANUAL.en.md)

## 1. 特長

- 背景を自動で除去し、透明PNGで保存
- 画像はブラウザ内だけで処理され、外部サーバーには送信されません
- 消しゴム・復元ブラシ・元に戻す(最大10回)で手直し
- 日本語 / English の表示切り替え(ブラウザの言語設定に合わせて自動選択)

## 2. 動作環境

- 最新のChrome / Edge(推奨)。WebGPU対応環境では高速に動作し、非対応でも動作します(WASMで処理、やや低速)
- 初回のみインターネット接続が必要です(AIモデル約170MBのダウンロード)。2回目以降はブラウザにキャッシュされます

## 3. 起動方法

1. `bg-remover` フォルダをターミナルで開きます。
2. 次のコマンドを実行します。

   ```
   python3 -m http.server 8000
   ```

3. ブラウザで `http://localhost:8000` を開きます。
4. 終了するときは、ターミナルで `Ctrl + C` を押します。

ポイント:

- `index.html` をダブルクリックして直接開くと、モデルのキャッシュが効かない場合があります。上記の方法を使ってください。
- モデルのキャッシュは「ポート番号ごと」に保存されます。毎回同じポート(例: 8000)で起動すると、再ダウンロードを避けられます。

## 4. 基本の使い方

1. **画像を読み込む**: 画面の枠に画像をドロップ、クリックしてファイルを選択、または ⌘V(Windowsは Ctrl+V)で貼り付けます。対応形式は PNG / JPG / WebP です。
2. **自動処理を待つ**: 初回はモデルのダウンロード状況が表示されます。その後「背景を除去中…」が表示され、完了すると結果が出ます。
3. **結果を確認する**: 透明部分は市松模様で表示されます。「元画像」タブで元の画像と見比べられます。
4. **必要なら手直しする**(次の章を参照)。
5. **保存する**: 「透明PNGを保存」を押すと、`元のファイル名_transparent.png` として保存されます。

## 5. 手直し(消しゴムと復元)

結果画面の上部に手直し用のツールがあります。

| ツール | 動作 |
|---|---|
| 消しゴム | なぞった部分を透明にします |
| 復元 | なぞった部分を元の画像の状態に戻します(消しすぎたときに使います) |
| サイズ | ブラシの大きさを 4〜200px で変更します。ブラシの円が画像上に表示されます |
| 元に戻す | 直前の操作を取り消します。最大10回まで戻れます。キーボードでは ⌘Z(Ctrl+Z) |

使い方のコツ:

- 大きく消したいときはサイズを大きく、細かい部分(髪の毛の周りなど)はサイズを小さくします。
- 消しすぎたら、まず「元に戻す」を使います。ずっと前の操作を直したい場合は「復元」ブラシで元の画像に戻せます。
- 「復元」は元の画像そのものを描き戻します。背景除去のAI処理の結果には戻りません。

## 6. 言語の切り替え

画面右上の「日本語 / English」で切り替えられます。選んだ言語は次回以降も保持されます。

## 7. 制限事項

- 4096px を超える大きな画像は、長辺4096pxに縮小して処理されます。
- 「元に戻す」は最大10回までです。
- 「別の画像」を押す、または新しい画像を読み込むと、編集中の内容は破棄されます。必要なら先に保存してください。
- 1枚ずつの処理です(一括処理には対応していません)。

## 9. トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「処理に失敗しました」と表示される | インターネット接続を確認してください。会社や学校のネットワークでは `huggingface.co` と `cdn.jsdelivr.net` への接続が制限されている場合があります。原因は、ブラウザの開発者ツール(⌥⌘I)のコンソールに表示されます。 |
| 初回の処理が遅い | モデルをダウンロードしているためです(約170MB)。2回目以降は速くなります。 |
| 毎回モデルをダウンロードしてしまう | 毎回同じポート番号で起動してください。ブラウザのサイトデータを消去した場合も再ダウンロードになります。 |
| 除去の精度が足りない | 消しゴムと復元ブラシで手直ししてください。背景と被写体の色が近い画像は苦手なことがあります。 |
| 処理が遅い・ブラウザが重い | WebGPU非対応の環境ではWASMで処理するため、時間がかかります。大きな画像は事前に縮小すると軽くなります。 |
