# 市販薬検索 使用マニュアル

厚生労働省「セルフメディケーション税制」対象品目リスト(Excel)から作った、オフラインで動く市販薬の検索ページです。商品名・成分・症状・製造販売業者・JANコードで探せます。

## 1. 同梱ファイル

| ファイル | 内容 |
|---|---|
| `otc_search.html` | 検索ページ本体。データを内蔵した単一ファイルで、インターネット接続なしで動きます |
| `build_otc_search.py` | 厚労省のExcelから `otc_search.html` を作り直すスクリプト |
| `使用manual.md` | このマニュアル |

## 2. 使い方(検索ページ)

### 2.1 開く

`otc_search.html` をダブルクリックして、ブラウザ(Chrome / Safari / Edge など)で開きます。インストールや設定は不要です。スマホ・タブレットでも使えます。

### 2.2 検索する

画面上部の検索欄に入力すると、入力に合わせて結果が更新されます。

- **検索対象:** 商品名、有効成分、製造販売業者、発売元、JANコード、効能・症状のことば
- **複数語(AND検索):** スペースで区切ると、すべてを含むものだけが出ます(例: `アセトアミノフェン 頭痛`)
- **表記ゆれ:** ひらがな・カタカナ、全角・半角の違いは区別しません(`ｱｾﾄｱﾐﾉﾌｪﾝ` や `あせとあみのふぇん` でも `アセトアミノフェン` に当たります)
- **症状で探す:** `頭痛`、`鼻水`、`せき`、`かゆみ`、`肩こり` のような症状でも探せます
- **並び:** 商品名に一致したものが最優先、次に効能・成分の一致、その他の順です
- **注意:** 漢字の読み(`とうつう` → `頭痛`)には対応していません

検索ワードはURLの末尾(`#q=...`)に保存されるので、ブックマークすると同じ検索を再現できます。

### 2.3 絞り込む

検索欄の下の「絞り込み」で条件を組み合わせられます。スマホなど狭い画面では折りたたまれているので、タップして開いてください。

| 項目 | 動き |
|---|---|
| 効能 | ボタンを複数選ぶと、そのどれかに当たるものを表示(OR) |
| 剤形 | 内服 / 外用(塗る) / 貼付 / 点眼 / 点鼻。複数選択はOR |
| 成分 | プルダウンで1つ選ぶ(選んだ成分を含む商品) |
| 製造販売業者 | 文字入力で部分一致。候補が出ます(例: `ロート`) |
| 並び順 | 関連順 / 50音順 / メーカー順 |
| 削除済みも表示 | リストから削除された品目も表示(初期状態は非表示) |
| 条件をクリア | 検索語を含めてすべて初期状態に戻す |

異なる項目どうし(効能と剤形と成分など)は、すべてを満たしたものだけが残ります(AND)。

### 2.4 結果の見方

1件のカードは、同じ商品名・同じ成分の商品をまとめたものです。メーカーが複数ある場合は、まとめて表示されます。

- **バッジ:** 効能カテゴリ、剤形。リストから削除された品目には「リスト削除」が付き、薄く表示されます
- **効能:** 成分・剤形・商品名からの推定です(4章を参照)
- **有効成分:** 成分名のボタンを押すと、その成分で絞り込みます
- **製造販売 / 発売元:** メーカー名
- **包装・JANコード:** 折りたたまれています。包装単位、JANコード、備考(追加日など)が見られます。JANコードが載っていない品目もあります

結果は60件ずつ表示され、続きは「さらに表示」で読み込みます。

### 2.5 タブ

| タブ | 内容 |
|---|---|
| 市販薬 | 商品の検索(上記) |
| 漢方処方 | 税制対象の漢方処方の一覧。処方名・症状で絞り込めます。「主な効能」は一般的な目安です |
| 薬局製造販売医薬品 | 薬局が製造販売する医薬品のうち、対象となる処方番号の一覧 |
| OTC検査薬 | 対象となる検査薬の一般的名称 |

「2027/1/1 追加」は、2027年1月1日から税制の対象に追加される項目です。

## 3. 収録範囲と注意

- **税制対象品目だけです。** 全ての市販薬を網羅したものではありません
- **現在の収録は非スイッチOTCの品目リストです。** 「スイッチOTC」のリスト(厚労省の `001705872.xlsx`)は含まれていません。取り込む方法は5章を参照してください
- **効能は推定です。** 元のExcelに効能の列はなく、有効成分・剤形・商品名から機械的に付けています。分類の誤りが混ざる可能性があります
- **医療上の判断には使えません。** 購入・服用の前に、必ず製品の添付文書・パッケージ、または薬剤師・登録販売者の説明を確認してください
- **データの時点:** ページ下部の「出典データ」に、各リストの時点(例: 品目リスト R8.09)を表示しています

## 4. 効能の付け方

商品ごとに次の順で判定します。

1. **有効成分**で大まかな系統を決めます(解熱鎮痛成分、抗ヒスタミン成分、鎮咳成分、点鼻の血管収縮成分、外用の消炎成分など)
2. **剤形**を、包装単位(錠・包・枚・mL・g)と商品名(「点鼻」「シロップ」「軟膏」など)から推定します
3. 成分の組み合わせと剤形から**効能カテゴリ**を決めます。商品名に「かぜ」「せき」「鼻炎」などが含まれる場合は、その表記も参考にします
4. 有効成分が「マオウ」だけの商品は漢方薬として扱い、商品名から処方(葛根湯・小青竜湯など)を判別して効能を付けます

主なカテゴリは次のとおりです。

| カテゴリ | 主な判定の目安 |
|---|---|
| かぜ薬 | 解熱鎮痛成分 + 抗ヒスタミン・鎮咳成分など |
| 解熱鎮痛薬 | アセトアミノフェン、アスピリン、エテンザミドなど(内服) |
| せき止め・去痰薬 | ジヒドロコデイン、デキストロメトルファン、ノスカピンなど |
| 鼻炎用内服薬 | 抗ヒスタミン成分(内服)+ 鼻づまり用成分など |
| 点鼻薬 | ナファゾリン、テトラヒドロゾリンなど(点鼻) |
| 点眼薬 | クロルフェニラミンなど(小容量の液体) |
| 外用鎮痛消炎薬 | サリチル酸メチル、サリチル酸グリコールなど(湿布・塗り薬) |
| 外用かゆみ止め | ジフェンヒドラミンなど(外用) |
| 漢方(かぜ・せき・鼻炎 / 関節痛・むくみ / 肥満・便秘) | 「マオウ」のみの商品を処方名から分類 |
| 胃腸薬 / 水虫・たむし薬 / 外用ステロイド / 発毛剤 | スイッチOTCの取り込み時に使います。現在の収録には該当商品がありません |
| その他(未分類) | 成分から判定できないもの |

## 5. データの更新・スイッチOTCの追加

### 5.1 準備

- Python 3 と `openpyxl`(`pip install openpyxl`)が必要です

### 5.2 手順

1. 厚生労働省の「セルフメディケーション税制(医療費控除の特例)について」のページから、対象品目リストのExcel(`.xlsx`)をダウンロードします
   - ページ: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000124853.html
   - スイッチOTC、非スイッチOTC、漢方製剤、OTC検査薬、薬局製造販売医薬品の各リストがあります
2. すべての `.xlsx` を1つのフォルダに入れます(ファイル名は何でも構いません)
3. `build_otc_search.py` を実行します

```
python3 build_otc_search.py --input <xlsxを入れたフォルダ> --output otc_search.html
```

- `--input`(`-i`)は入力フォルダで、省略すると現在のフォルダを使います
- `--output`(`-o`)は出力ファイル名で、省略すると `otc_search.html` になります

4. 出力された `otc_search.html` を開きます

### 5.3 ファイルの判別

ファイル名ではなく、表の見出し行の内容で種類を判別します。

| 見出し | 扱い |
|---|---|
| `販売名` | 品目リスト(スイッチOTC / 非スイッチOTC) |
| `処方番号` | 薬局製造販売医薬品リスト |
| `処方名` | 漢方製剤リスト |
| `一般的名称` | OTC検査薬リスト |

「有効成分リスト」のExcelは、検索には使いません(無視されます)。

### 5.4 効能ルールを追加する

実行時に、効能ルールのない成分がコンソールに一覧表示されます。`build_otc_search.py` 内の次の辞書に追記すると、その成分が分類されます。

| 場所 | 用途 |
|---|---|
| `EXTRA_RULES` | 成分名(部分一致)から効能カテゴリを決めるルール |
| `KAMPO_EFF` | 漢方処方名 → 効能カテゴリと効能の説明 |
| `CATEGORIES` | カテゴリ名、効能の説明、検索用キーワード |

## 6. トラブルシューティング

| 症状 | 対処 |
|---|---|
| 検索しても何も出ない | 「条件をクリア」を押してください。「削除済みも表示」がオフだと、削除された品目は出ません |
| 探している商品がない | 税制対象外の可能性があります。スイッチOTCのリスト未取り込みの場合もあります |
| 検索欄が画面上部に固定される | 仕様です(スクロールしても検索できるようにしています) |
| `No .xlsx files found` と出る | `--input` のフォルダに `.xlsx` が入っているか確認してください |
| 品目が0件になる | 厚労省の表の見出し(`販売名` など)が変わっていないか確認してください |
| `ModuleNotFoundError: openpyxl` | `pip install openpyxl` を実行してください |
