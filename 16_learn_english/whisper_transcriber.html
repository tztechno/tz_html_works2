4. 実行

このツールについて： 文字起こしは Transformers.js を用いて OpenAI Whisper モデルをブラウザ内（WebAssembly / WebGPU）で実行しています。 サーバーへの音声アップロードは一切行われません。最も安定して動作するのは Chrome または Edge の最新版 です。 このページを Claude の会話内プレビューではなく、ダウンロードしてブラウザで直接開くことを推奨します（モデルのダウンロード・キャッシュが正しく動作するためです）。
