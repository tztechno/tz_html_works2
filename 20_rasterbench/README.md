# Rasterbench

画像フォーマットを一括変換するWebツールです。すべての処理はブラウザ内で完結し、画像がサーバーにアップロードされることはありません。

公開ページ: https://claude.ai/code/artifact/d20d9c73-b434-4deb-836b-39d1c551e1ea

## 対応フォーマット

| | フォーマット |
|---|---|
| 読み込み（入力） | PNG / JPEG / WebP / GIF / BMP / SVG |
| 変換先（出力） | PNG / JPEG / WebP / GIF |

SVGはラスター画像（ビットマップ）に変換されます。ベクター形式のまま書き出すことはできません。

BMPは読み込み専用です。ブラウザの保存機能が対応している拡張子の都合上、BMP形式そのものへの書き出しはできません。

## 使い方

1. ページ中央のドロップゾーンに画像ファイルをドラッグ&ドロップするか、クリックしてファイルを選択します。複数ファイルをまとめて追加できます。
2. 「変換先フォーマット」からPNG / JPEG / WebP / GIFのいずれかを選びます。
3. 「すべて変換」を押すと、追加した画像が順番に変換されます。各行の完了バッジが「完了」になれば変換終了です。
4. ファイルを保存します。
   - 1件ずつ保存する場合: 各行の「ダウンロード」ボタンを押します。
   - まとめて保存する場合: 「すべてダウンロード」を押すと、変換済みファイルを1件ずつ順番に保存確認します。
5. 保存を求める確認画面が表示されるので、都度「保存」を選択してください。保存を1件キャンセルしても、残りのファイルの保存は続けられます。

## 変換に関する注意点

- **透過情報について**: JPEGおよびGIFには透過（アルファチャンネル）がないため、変換すると透明部分は白で塗りつぶされます。透過を保ちたい場合はPNGまたはWebPを選んでください。
- **GIFの色数**: GIF出力は最大256色に減色されます（メディアンカット法による自動減色）。写真など色数の多い画像では階調がやや粗くなることがあります。
- **アニメーションGIF**: 変換結果は常に単一フレームです。アニメーションGIFを読み込んだ場合も、書き出されるのは先頭フレームのみです。
- **ファイルサイズ**: 1ファイルあたり16MBを超える場合、保存時にエラーになることがあります。

## テーマ

右上のボタンで「システム設定 / ライト / ダーク」の表示テーマを切り替えられます。

## プライバシー

画像の読み込み・変換・書き出しはすべてこのページを開いているブラウザの中だけで行われます。外部サーバーへの送信は一切ありません。
