# Poly Bench 使用マニュアル

**ブラウザだけで完結する3Dモデルフォーマット変換ツール**

Poly Benchは、OBJ・STL・PLY・glTF・GLB形式の3Dモデルをドラッグ＆ドロップするだけで、他の対応フォーマットに変換してダウンロードできるツールです。処理はすべてブラウザ内のローカルで完結し、どこにもアップロードされません。このツールは変換専用です。変換せずにモデルを確認・回転させたいだけの場合は、姉妹ツールの「Poly Viewer」をご利用ください。

インターフェースは日英バイリンガル対応です。右上の**EN / 日本語**トグルでいつでも切り替えられます。ラベル・パネルの見出し・ステータスメッセージはすべてその場で切り替わります。

---

## 1. 動作環境

- WebGLに対応した最新のデスクトップ用ブラウザ（Chrome、Edge、Firefox、Safariなど）。
- 初回起動時のみ、インターフェースで使用するGoogle Fontsを読み込むためインターネット接続が必要です。3Dエンジン本体はファイル内にバンドルされているため、それ以外のネットワークアクセスは不要です — モデルの読み込み・変換はその後完全にオフラインで動作します。
- HTMLファイルをダブルクリックして直接開くか、ブラウザにドラッグ＆ドロップしてください。サーバーの起動は不要です。

## 2. モデルの読み込み方

1. ファイルをひとつまたは複数、**ドロップゾーンにドラッグ＆ドロップ**するか、**「ファイルを選択」**をクリックしてファイルピッカーを開きます。
2. モデルが複数ファイルで構成されている場合は、**関連ファイルをすべてまとめて選択**してください:
   - マテリアル付きの**.obj**には**.mtl**ファイルと、そこから参照されるテクスチャ画像（.png/.jpg/.jpeg/.webp/.tga/.bmp）が必要です。
   - **.gltf**（バイナリでない形式）には**.bin**ファイルとテクスチャ画像が必要です。単体の**.glb**はそれ自体で完結しています。
   - **.stl**・**.ply**は単体で完結しています。
3. Poly Benchは、認識できる拡張子（obj, stl, ply, gltf, glb）を持つ最初のファイルを読み込むモデルとして扱い、残りは関連ファイル（マテリアル・バッファ・テクスチャ）として扱います。FBXおよびUSD/USDZは入力として受け付けません。詳しくは[6章 制限事項](#6-制限事項)を参照してください。
4. 読み込みが完了するとドロップゾーンは消え、ビューポートにモデルが表示され、インスペクターに**「出力設定」**パネルが現れます。別のモデルからやり直したい場合は、いつでも**「別のモデルを読み込む」**をクリックしてください。

## 3. ビューポートの操作

モデルを読み込むと、3Dビュー上に簡易的なHUD（情報表示）とツールバーが表示されます。

- **フォーマットチップ**（左上）— 検出されたファイル形式を表示します。
- **三角形数チップ** — 読み込まれたメッシュの三角形の総数です。
- **ツールバー**（左下）、2つのボタン:
  - **ビューをリセット** — カメラをモデルに合わせて再フレーミングします。
  - **ワイヤーフレーム切替** — メッシュを線（エッジ）のみで表示します。
- **マウス・タッチ操作** — ドラッグで視点回転、スクロール（またはピンチ）でズーム、右ドラッグでパン（標準的なオービットカメラ操作）。

Poly Benchのビューポートは、正しいファイルを読み込めたかを確認するためのものであり、詳細なインスペクターではありません。アニメーション再生・ボーン表示・詳細な統計情報が必要な場合は「Poly Viewer」をご利用ください。

## 4. 出力フォーマットの選択と変換

**出力設定**パネルには、**出力フォーマット**のドロップダウンがひとつあり、7つの選択肢があります。

| 選択肢 | 生成されるもの |
|---|---|
| glTF (.gltf, text) | JSON形式のglTFファイル（マテリアル・テクスチャ・ボーン・アニメーションを参照または埋め込み） |
| GLB (.glb, binary) | glTFのバイナリ単一ファイル形式 |
| OBJ (.obj) | プレーンテキストのOBJ（ジオメトリとUVのみ） |
| STL (.stl, binary) | バイナリSTL（三角形メッシュのみ） |
| STL (.stl, text) | ASCII STL（三角形メッシュのみ） |
| PLY (.ply, binary) | バイナリPLY（ジオメトリ・法線・頂点カラー） |
| PLY (.ply, text) | ASCII PLY（ジオメトリ・法線・頂点カラー） |

ドロップダウンの下にある**互換性メモ**は、フォーマットを変更するたびに自動的に更新されます。

- 緑のチェックマークは、選択したフォーマットが読み込んだモデルのすべてのデータを保持できることを示します。
- オレンジの警告は、変換によって**失われる**データを具体的にリストします — 例えば、アニメーション付きでテクスチャのあるglTFを読み込み、出力にOBJを選んだ場合、「OBJは以下を保持できません: アニメーション、ボーン / スキニング、テクスチャ」のように表示されます。

フォーマットを決めたら、**「変換してダウンロード」**をクリックします。Poly Benchはモデルをメモリ上で変換し、対応する拡張子のファイル名で結果を保存します。ボタン下のステータス行に、進行状況（「書き出し中…」）と結果（「保存しました: model.glb」）またはエラーが表示されます。

## 5. 各フォーマットが保持するデータ

これは、インスペクター内の**「フォーマット別の保持データ」**表と同じ内容で、どのモデルを読み込んでいるかに関わらず参照できます。

| フォーマット | 保持されるデータ |
|---|---|
| OBJ | 頂点・面・UV（マテリアルは非対応） |
| STL | 三角形メッシュのみ（色・テクスチャなし） |
| PLY | 頂点・法線・頂点カラー |
| glTF/GLB | メッシュ・PBRマテリアル・テクスチャ・ボーン・アニメーション |

より情報量の多いフォーマット（glTF/GLB）からよりシンプルなフォーマット（OBJ・STL・PLY）への変換は片道切符です。変換先のフォーマットが表現できないデータは失われ、再度変換しても元には戻りません。特定のデータを残す必要がある場合は、変換前に必ず互換性メモを確認してください。

## 6. 制限事項

- **FBXおよびUSD/USDZには、ライセンス上の理由により非対応です。** Poly Benchはこれらの形式の読み込み・書き出しのどちらもできません。これらの形式を扱う必要がある場合は、別のツールで先にglTF/GLBへ変換するか、応急的な確認手段として「Poly Viewer」（FBXとUSD/USDZを実験的に表示可能）をご利用ください。
- **Draco圧縮されたglTF/GLBは入力として非対応です。** .glbがDracoメッシュ圧縮でエクスポートされている場合、読み込みに失敗します。Draco圧縮を使わずに再エクスポートしてください。
- ファイル一式のサイズは、合計およそ**100MB**までです。
- Claudeの会話上のライブプレビューからPoly Benchを開いた場合（ダウンロード済みのスタンドアロンHTMLファイルとしてではなく）、一部またはすべての出力フォーマットで直接のダウンロードができないことがあります。その場合はアプリがその旨を表示し、スタンドアロン版のファイルを案内します。詳しくは[8章 トラブルシューティング](#8-トラブルシューティング)を参照してください。

## 7. プライバシーについて

ファイルの読み込み・変換・生成は、すべてお使いの端末のブラウザ内で行われます。ファイルやファイル名、モデルデータがどこかに送信されることはありません。社外秘・未公開のモデルも安心して変換いただけます。

## 8. トラブルシューティング

| 症状 | 想定される原因・対処法 |
|---|---|
| ファイルをドロップしても何も起こらない | ドロップしたファイルのいずれも認識可能な拡張子（obj/stl/ply/gltf/glb）ではありませんでした。FBXおよびUSD/USDZは受け付けません — [6章 制限事項](#6-制限事項)を参照してください。 |
| 「読み込みに失敗しました: ...」と表示される | 対応拡張子ではあるものの、解析に失敗しました。ファイルが破損している、非対応の機能（Draco圧縮など）を使用している、または関連ファイル（.mtl、.bin、テクスチャ）が不足している可能性があります。 |
| 互換性メモに想定外の警告が出る | 読み込んだモデルに、選択した出力フォーマットが表現できないデータ（アニメーション・ボーン・マテリアル・テクスチャ・頂点カラーなど）が含まれています。それらを残したい場合は、より情報量の多いフォーマット（glTF/GLB）を選んでください。 |
| 「このプレビュー画面ではダウンロードを実行できません…」と表示される | Claudeの会話上のライブプレビュー内でPoly Benchを実行しており、これらのファイル形式を直接保存できません。会話からスタンドアロン版のHTMLファイルをダウンロードし、ブラウザで開いてご利用ください。そちらでは通常どおり動作します。 |
| 「このプレビュー画面では『.xxx』形式を直接保存できません…」と表示される | 上記と同じ原因で、特定のフォーマットについて発生しています。スタンドアロン版のファイルをご利用ください。 |
| 「保存をキャンセルしました。」と表示される | 保存ダイアログがキャンセルされました（ご自身の操作、またはブラウザによる場合があります）。もう一度**「変換してダウンロード」**をクリックしてください。 |
| 変換せずにこのモデルを見たり回転させたりしたいだけ | 変換せずに表示専用で使いたい場合は、姉妹ツールの「Poly Viewer」をご利用ください。アニメーション・ボーン・詳細な統計情報の確認にも対応しています。 |
