# Poly Viewer 使用マニュアル

**ブラウザだけで完結する3Dモデルビューア**

Poly Viewerは、OBJ・STL・PLY・glTF・GLB・FBX・USD/USDZ形式の3Dモデルをドラッグ＆ドロップするだけで、その場で確認できるツールです。回転させたり、ワイヤーフレーム表示に切り替えたり、埋め込まれたアニメーションを再生したり、頂点数・三角形数・マテリアル数などを確認できます。処理はすべてブラウザ内のローカルで完結し、どこにもアップロードされません。このビューアは表示専用です。フォーマット変換が必要な場合は、姉妹ツールの「Poly Bench」をご利用ください。

インターフェースは日英バイリンガル対応です。右上の**EN / 日本語**トグルでいつでも切り替えられます。ラベル・パネルの見出し・ツールチップ・ステータスメッセージはすべてその場で切り替わります。

---

## 1. 動作環境

- WebGLに対応した最新のデスクトップ用ブラウザ（Chrome、Edge、Firefox、Safariなど）。
- 初回起動時のみ、インターフェースで使用するGoogle Fontsを読み込むためインターネット接続が必要です。3Dエンジン本体はファイル内にバンドルされているため、それ以外のネットワークアクセスは不要です — モデルの読み込み・表示はその後完全にオフラインで動作します。
- HTMLファイルをダブルクリックして直接開くか、ブラウザにドラッグ＆ドロップしてください。サーバーの起動は不要です。

## 2. モデルの読み込み方

1. ファイルをひとつまたは複数、**ドロップゾーンにドラッグ＆ドロップ**するか、**「ファイルを選択」**をクリックしてファイルピッカーを開きます。
2. モデルが複数ファイルで構成されている場合は、**関連ファイルをすべてまとめて選択**してください:
   - マテリアル付きの**.obj**には**.mtl**ファイルと、そこから参照されるテクスチャ画像（.png/.jpg/.jpeg/.webp/.tga/.bmp）が必要です。
   - **.gltf**（バイナリでない形式）には**.bin**ファイルとテクスチャ画像が必要です。単体の**.glb**はそれ自体で完結しています。
   - **.stl**・**.ply**・**.fbx**・**.usd/.usda/.usdc/.usdz**は基本的に単体で完結していますが、FBXとUSDは外部テクスチャを参照する場合もあります。
3. Poly Viewerは、認識できる拡張子（obj, stl, ply, gltf, glb, fbx, usd, usda, usdc, usdz）を持つ最初のファイルを読み込むモデルとして扱い、残りは関連ファイル（マテリアル・バッファ・テクスチャ）として扱います。
4. 読み込みが完了するとドロップゾーンは消え、ビューポートにモデルが表示されます。別のモデルに切り替えたい場合は、インスペクターパネルの**「別のモデルを読み込む」**をいつでもクリックしてください。

ドロップしたファイルのいずれも対応拡張子でない場合や、ファイルの解析に失敗した場合は、ドロップゾーンの案内文の代わりにエラー内容が表示されます。詳しくは[8章 トラブルシューティング](#8-トラブルシューティング)を参照してください。

## 3. ビューポートの操作

モデルを読み込むと、3Dビュー上にHUD（情報表示）とツールバーが表示されます。

- **フォーマットチップ**（左上）— 検出されたファイル形式（OBJ、STL、GLTFなど）を表示します。
- **三角形数チップ** — 読み込まれたメッシュの三角形の総数です。
- **実験的パースチップ** — FBXおよびUSD/USDZファイルの場合のみ表示されます。これらのパーサーは他の形式より新しく、実績が少ないためです（[6章 対応フォーマットと制限](#6-対応フォーマットと制限)を参照）。
- **ツールバー**（左下）、4つのボタン:
  - **ビューをリセット** — カメラをモデルに合わせて再フレーミングします。
  - **ワイヤーフレーム切替** — メッシュを線（エッジ）のみで表示します。
  - **グリッド表示切替** — 床面の基準グリッドの表示・非表示を切り替えます。
  - **自動回転切替** — モデルを垂直軸を中心にゆっくり回転させます。
- **マウス・タッチ操作** — ドラッグで視点回転、スクロール（またはピンチ）でズーム、右ドラッグでパン（標準的なオービットカメラ操作）。

## 4. アニメーション再生

読み込んだモデルにアニメーションクリップが含まれている場合（glTF/GLBやFBXでよくあります）、ビューポート下部中央にトランスポートバーが表示されます。

- **再生 / 一時停止**ボタン。
- **クリップ選択** — モデルに複数のアニメーションクリップがある場合、再生するクリップを選べます。
- **スクラバー（シークバー）** — ドラッグして現在のクリップの任意の位置にジャンプできます。
- **時間表示** — 現在の再生時間 / クリップ全体の長さ（秒）。

アニメーションデータを持たないモデルでは、このバーは表示されません。

## 5. インスペクターパネル

右側のパネルは3つのセクションで構成されています。

**読み込み中のモデル** — ファイル名と、それに続く6つの統計情報（頂点、三角形、マテリアル、テクスチャ、アニメーション、ボーン）を表示します。これらは、ワイヤーフレームなどの表示設定による見た目の変化とは関係なく、読み込まれたモデルそのものの値です。

**表示設定** — 5つのトグルで、すべて見た目のみに影響する任意設定です（Poly Viewerは何も書き出さないため、これらの設定がモデルデータ自体に影響することはありません）:
- **スタジオ照明（IBL）** — イメージベースドライティングにより、より自然で均一な陰影になります。デフォルトでオン。
- **環境を背景に表示** — 照明に使われている環境そのものを、通常の背景の代わりにモデルの後ろに表示します。デフォルトでオフ。
- **グリッド表示** — 床面の基準グリッド。デフォルトでオン。ビューポートツールバーのグリッド切替と連動しています。
- **自動回転** — ツールバーの自動回転切替と連動しています。
- **ワイヤーフレーム** — ツールバーのワイヤーフレーム切替と連動しています。

**対応フォーマットと制限** — 常時表示される参照用の表です（次章を参照）。

## 6. 対応フォーマットと制限

| 形式 | 対応状況 |
|---|---|
| OBJ | MTL・テクスチャを含めて対応 |
| STL | ASCII / バイナリとも対応 |
| PLY | ASCII / バイナリ・頂点カラーに対応 |
| glTF/GLB | PBRマテリアル・ボーン・アニメーションに対応 |
| FBX | ジオメトリ・マテリアル・ボーン・アニメーションに対応（実験的） |
| USD/USDZ | 基本的なメッシュ・マテリアルに対応（実験的、レイヤー合成等は非対応） |

フォーマットに関わらず、以下の2点にご注意ください:

- **Draco圧縮されたglTF/GLBには非対応です。** .glbがDracoメッシュ圧縮でエクスポートされている場合、読み込みに失敗します。Draco圧縮を使わずに再エクスポートしてください。
- **FBXおよびUSD/USDZのパーサーは実験的実装です。** 一般的なケースはカバーしていますが、OBJ/STL/PLY/glTFのパーサーほど成熟していないため、これらの形式の一部のファイルは正しく表示されない、または読み込みに失敗する場合があります。

## 7. プライバシーについて

ファイルの読み込み・解析・描画は、すべてお使いの端末のブラウザ内で行われます。ファイルやファイル名、モデルデータがどこかに送信されることはありません。社外秘・未公開のモデルも安心して確認いただけます。

## 8. トラブルシューティング

| 症状 | 想定される原因・対処法 |
|---|---|
| 「対応拡張子のファイルが見つかりませんでした」と表示される | ドロップしたファイルのいずれも認識可能な拡張子（obj/stl/ply/gltf/glb/fbx/usd/usda/usdc/usdz）ではありませんでした。ファイル形式を確認するか、テクスチャだけでなくモデル本体のファイルも含まれているか確認してください。 |
| 「読み込みに失敗しました: ...」と表示される | 対応拡張子ではあるものの、解析に失敗しました。ファイルが破損している、非対応の機能（Draco圧縮など）を使用している、または関連ファイル（.mtl、.bin、テクスチャ）が不足している可能性があります。 |
| モデルは読み込めるがテクスチャがない／グレーに見える | 参照先のテクスチャや.mtl/.binファイルが選択に含まれていませんでした。関連ファイルをすべてまとめて選び直してください。 |
| FBXやUSDファイルの見た目がおかしい、または読み込みに失敗する | これらのパーサーは実験的実装です（6章参照）。一部のファイルはまだ十分に対応できていません。 |
| フォルダをドロップしても反応しない | フォルダ自体ではなく、フォルダの中の個々のファイルをドロップまたは選択してください。 |
| アニメーションのトランスポートバーが表示されない | 読み込んだモデルにアニメーションクリップが含まれていません。 |
| このファイルを別の形式に変換したい | Poly Viewerは仕様上、表示専用です。変換には姉妹ツールの「Poly Bench」をご利用ください。 |
