# Shorts Video/Audio Combiner — 利用マニュアル

動画と音声ファイルをショート動画向けの長さにトリムして結合する、ローカルで動くシンプルなWebアプリです。自分のマシン上の本物の`ffmpeg`を使って処理します。

## 1. 必要なもの

- Python 3.8以降
- `ffmpeg`本体(システムのPATHに通っていること)
  - macOS: `brew install ffmpeg`
  - Ubuntu/Debian: `sudo apt install ffmpeg`
  - Windows: [ffmpeg.org](https://ffmpeg.org/download.html)からインストールし、PATHに追加
- このマニュアルと一緒に渡している`app.py`と`requirements.txt`

## 2. インストール

`app.py`と`requirements.txt`があるフォルダでターミナルを開き、以下を実行します。

```
pip install -r requirements.txt
```

これでFlaskと`ffmpeg-python`がインストールされます。`ffmpeg`本体はこれには含まれないので、上記の方法で別途インストールしてください。

## 3. アプリの起動

同じフォルダで以下を実行します。

```
python app.py
```

以下のような出力が表示されれば起動成功です。

```
 * Running on http://127.0.0.1:5000
```

ブラウザでこのアドレス(`http://127.0.0.1:5000`)を開いてください。アプリを使っている間はターミナルを閉じないでください(閉じるとサーバーが停止します)。

停止したい時はターミナルに戻って`Ctrl+C`を押してください。

もしブラウザに「ffmpeg is not installed」というページが表示された場合は、アプリ自体は起動できているものの`ffmpeg`コマンドが見つからない状態です。手順1に戻ってインストールし、`python app.py`をやり直してください。

## 4. 使い方

1. **Video file** — 元になる動画ファイルを選択します(`.mov`や`.mp4`など)。
2. **Audio file** — 重ねたい音声ファイルを選択します(`.mp3`など)。
3. **Audio volume** — 音声トラックの音量倍率です。`1.0`で元の音量のまま、`0.08`のようにかなり小さくすることも、`1.0`より大きくして音量を上げることもできます。
4. **Max short duration (seconds)** — short-formモードがONのとき、出力をこの秒数以内に収めます。`178`はYouTube ShortsやTikTok系の短尺動画の上限(約3分)に近い値です。
5. **Short-form mode**のチェックボックス:
   - **ON**: 1080×1920の縦長フレームに合わせてスケール・パディング(必要に応じて黒帯を追加)し、上記の最大秒数以内にトリムします。
   - **OFF**: 元動画のサイズと長さをそのまま維持します(縦長への変換も秒数の上限もかかりません)。
6. **Convert**をクリックします。処理時間は動画の長さやマシンの性能によりますが、短いクリップなら数秒で終わります。
7. 成功すると結果のプレビューと**Download**ボタンが表示され、`.mp4`ファイルを保存できます。もう一度変換したい場合は**Convert another**をクリックしてください。

## 5. 内部で行っていること(参考)

各変換時に`ffmpeg`で行っている処理は以下の通りです。

1. 元動画の長さを取得します。
2. short-formモードがONなら目標の長さは`min(元動画の長さ, 最大秒数)`、OFFなら元動画の長さそのままになります。
3. 音声をその目標の長さにトリムし、音量フィルターを適用して一時的な音声ファイルとして書き出します。
4. 動画も同じ目標の長さにトリムし、トリム済みの音声と結合します(動画は動画ファイル側から、音声はトリム済み音声ファイル側から明示的に指定するため、ffmpegが取り違えることはありません)。short-formモードの場合はここで1080×1920へのスケール・パディングも行います。
5. 結果をH.264(映像)+AAC(音声)、`faststart`付きのMP4として書き出します(ダウンロード完了前から再生を開始できるようにするためのオプションです)。
6. アップロードされた一時ファイルとトリム済み音声の中間ファイルは変換後に削除されます。最終的な出力ファイルは`app.py`と同じ階層の`outputs`フォルダに残り続けるので、不要になったら手動で削除してください。

## 6. トラブルシューティング

- **「Please choose both a video file and an audio file.」** — 動画か音声のどちらか(または両方)を選択せずに送信しています。
- **長いログとともに「ffmpeg failed」ページが出る** — `ffmpeg`自身が出したエラーログです。多くの場合、対応していない形式や壊れた入力ファイルが原因です。ログの終わり付近に具体的な原因が書かれていることが多いです。
- **ポートが使用中というエラー** — 別のプログラムが既にポート5000を使っています。そのプログラムを止めるか、`app.py`の最終行(`app.run(debug=True, port=5000)`)のポート番号を`port=5001`などに変更してください。
- このアプリはFlask標準の開発用サーバーを使っているため、個人のローカル利用を想定しています。インターネットに公開する用途には向いていません。
