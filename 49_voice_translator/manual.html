Kotoba Booth

User Manual

Kotoba Booth is a two-way English ⇄ Japanese translator. Speak or type, and it translates and reads the result aloud.

1. Getting started

On a smartphone

  1. Open the Kotoba Booth web address in Safari (iPhone) or Chrome (Android). It must be an https:// address, or the microphone will not work.
  2. Add it to your home screen: Safari → Share → Add to Home Screen; Chrome → ⋮ menu → Add to Home screen. It then opens full screen like an app.
  3. Allow microphone access when your phone asks.
  4. The first translation downloads the translation model: about 145 MB per direction. Use Wi-Fi for this step. After that it is stored on your phone.

On a computer

Open the same address in Chrome, Edge or Safari. The interface is the same, with the controls laid out side by side.

To switch the interface language, tap 日本語 / English at the top of the app. Your choice is remembered.

2. The screen

Direction: AUTO · JA → EN · EN → JA
AUTO detects the language of what you type. Choose a fixed direction if detection guesses wrong, for example with short romaji words.
Source
The text to translate. You can type, paste or dictate into it. The label shows the detected language.
⇅ Swap
Swaps the source and the translation, so you can reply in the other direction.
Translation
The result, with 🔊 Speak, ⏹ (stop speaking) and Copy.
Bottom bar (phone)
🎤 日本語 and 🎤 English start voice input in that language. 🔊 reads the source aloud. Translate runs the translation.
History
Your last 30 translations. Tap 🔊 on a row to hear it again. History is kept only in this browser.

3. Translate by voice

  1. Tap the microphone for the language you will speak: 🎤 English to speak English, 🎤 日本語 to speak Japanese.
  2. Speak one or two sentences. Gray text shows what is being recognised.
  3. Stop talking. Recognition ends by itself, or tap ⏺ Stop.
  4. The text is translated and read aloud in the other language.
For a conversation, put the phone between you. Each person taps their own language's microphone before speaking.

4. Translate by typing

  1. Type or paste into Source.
  2. Tap Translate. On a computer you can also press ⌘/Ctrl + Enter.
  3. Long text is translated sentence by sentence and appears as each sentence finishes. Tap Stop to cancel.

5. Reading aloud

Speech uses the voices built into your device. Open ⚙︎ Settings to choose a voice for each language (a sample plays when you pick one) and to set the speed.

English read with a Japanese accent? Your device has no English voice installed, or none was selected. Pick one under EN voice. If the list shows “(none)”, add a voice in your device settings. iPhone: Settings → Accessibility → Spoken Content → Voices. Mac: System Settings → Accessibility → Spoken Content → System Voice → Manage Voices.

6. Translation engines

Choose the engine under ⚙︎ Settings → engine.

EngineWhere it runsGood forNeeds
In-browser (FuguMT)On your device. Works offline after the first downloadPhones, travel, privacy~145 MB per direction on first use
Ollama (local)A local AI model on your computerLonger or casual text, better nuanceOllama running on the same computer (ollama serve)
ClaudeClaude, when the page is opened inside ClaudeBest overall qualityOnly available in the Claude-hosted version

FuguMT is a small model made only for translation, and it works one sentence at a time. It handles clear, standard sentences well. Slang, names and very long sentences can come out awkwardly. For those, use Ollama or Claude when you can.

7. Settings

8. Troubleshooting

The microphone buttons do nothing / “Microphone permission denied”
Check that the address starts with https://. Allow the microphone for the site: iPhone Settings → Safari → Microphone, or Chrome → site settings. If you use Kotoba Booth inside Claude, the microphone is blocked there. Use your keyboard's dictation key, or open the standalone version.
“This browser does not support speech recognition”
Use Safari on iPhone or Chrome on Android and computers. Firefox does not support it.
The model download stops or fails
Connect to Wi-Fi, reload, and try again. Downloads that stop partway resume on the next try. Make sure the phone has about 400 MB of free space.
Translation is slow
The first run after opening the app loads the model into memory, which takes a few seconds. After that, each sentence takes about 1–5 seconds, depending on the phone.
“Cannot reach Ollama”
Run ollama serve on the computer. If the browser blocks the connection, start it with OLLAMA_ORIGINS="*" ollama serve. Ollama only works from the computer it runs on.
Wrong direction
Pick JA → EN or EN → JA instead of AUTO.

9. Privacy

  • In-browser (FuguMT): translation runs on your device. Your text is not sent anywhere.
  • Voice input uses your browser's speech recognition. Chrome and some Safari configurations send audio to the browser maker's servers to recognise it.
  • Ollama stays on your computer. Claude sends the text to Claude to translate it.
  • Settings and history are stored only in this browser. Clearing site data removes them.

10. Mac desktop app

voice_translator.py is a separate desktop version for Mac that runs fully offline. It uses Whisper for speech recognition, Ollama for translation and the macOS say command for speech.

  1. In Terminal, in the app folder: python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
  2. Start Ollama, then run python voice_translator.py
  3. Press 🎤 Record (⌘R), speak, press again to stop. The translation appears and is read aloud.

1. はじめに

スマートフォンで使う

  1. Kotoba Booth のアドレスを Safari（iPhone）または Chrome（Android）で開きます。アドレスは https:// で始まる必要があります。そうでないとマイクが使えません。
  2. ホーム画面に追加します。Safari は 共有 →「ホーム画面に追加」、Chrome は ⋮ メニュー →「ホーム画面に追加」です。以後はアプリのように全画面で開きます。
  3. マイクの使用を求められたら「許可」を選びます。
  4. 最初の翻訳で翻訳モデルをダウンロードします（1方向あたり約145MB）。この操作は Wi-Fi で行ってください。以後は端末に保存されます。

パソコンで使う

同じアドレスを Chrome・Edge・Safari で開きます。機能は同じで、横に広い画面向けの配置になります。

画面の言語は、アプリ上部の English / 日本語 で切り替えられます。選んだ言語は記憶されます。

2. 画面の見方

翻訳の向き：AUTO · JA → EN · EN → JA
AUTO は入力した文の言語を自動で判定します。短いローマ字など、判定を間違えるときは向きを固定してください。
原文
翻訳したい文です。入力・貼り付け・音声入力ができます。見出しに判定した言語が表示されます。
⇅ 入れ替え
原文と訳文を入れ替えます。相手への返事を逆向きに訳すときに便利です。
訳文
翻訳結果です。🔊 読み上げ、⏹（読み上げ停止）、コピー ボタンがあります。
下部バー（スマホ）
🎤 日本語 と 🎤 English で、その言語の音声入力を始めます。🔊 は原文の読み上げ、翻訳 は翻訳の実行です。
履歴
直近30件の翻訳です。各行の 🔊 でもう一度聞けます。履歴はこのブラウザ内にだけ保存されます。

3. 音声で翻訳する

  1. 話す言語のマイクを押します。日本語で話すなら 🎤 日本語、英語で話すなら 🎤 English です。
  2. 1〜2文を話します。認識中の文字が灰色で表示されます。
  3. 話し終えると自動で認識が終わります。途中で止めるときは ⏺ 停止 を押します。
  4. 自動で翻訳され、相手の言語で読み上げます。
会話で使うときは、スマホを2人の間に置きます。話す人が、それぞれ自分の言語のマイクを押してから話してください。

4. 文字で翻訳する

  1. 原文に文を入力するか、貼り付けます。
  2. 翻訳 を押します。パソコンでは ⌘/Ctrl + Enter でも実行できます。
  3. 長い文は一文ずつ翻訳し、終わった順に表示します。途中でやめるときは 中止 を押します。

5. 読み上げ

読み上げには端末に入っている音声を使います。⚙︎ 設定 で、言語ごとの音声（選ぶと見本が流れます）と速度を選べます。

英語が日本語なまりで読まれる場合：端末に英語の音声が入っていないか、選ばれていません。「英語の音声」で英語の声を選んでください。一覧が「(none)」のときは、端末の設定で音声を追加します。iPhone は 設定 → アクセシビリティ → 読み上げコンテンツ → 声、Mac は システム設定 → アクセシビリティ → 読み上げコンテンツ → システムの声 → 声を管理 です。

6. 翻訳エンジン

⚙︎ 設定 → エンジン で切り替えます。

In-browser (FuguMT)端末の中。初回のダウンロード後はオフラインでも動くスマホ、旅行、プライバシー重視初回に1方向あたり約145MB
Ollama (local)パソコン上のローカルAI長文・口語、自然な言い回し同じパソコンで Ollama を起動（ollama serve）

FuguMT は翻訳専用の小さなモデルで、一文ずつ訳します。標準的なはっきりした文は得意ですが、くだけた言い回し・固有名詞・非常に長い文は不自然になることがあります。そういう文は、使える環境なら Ollama か Claude で訳してください。

7. 設定

翻訳結果を自動で読み上げ
翻訳が終わるたびに自動で読み上げます。
音声入力後に自動翻訳
音声入力が終わるとすぐ翻訳します。文字を直してから訳したいときはオフにします。
英語の音声 / 日本語の音声
言語ごとに使う声です。auto を選ぶと、使える中で最適な声を自動で選びます。
速度
読み上げの速さです（0.6〜1.6倍）。
エンジン
翻訳エンジンです（6章を参照）。Ollama では、モデル名（例：gemma4:e4b）も指定できます。

8. 困ったときは

マイクボタンが反応しない／「マイクが許可されていません」と出る
アドレスが https:// で始まっているか確認してください。サイトにマイクを許可します（iPhone は 設定 → Safari → マイク、Chrome はサイトの設定）。Claude 上で使っている場合、マイクはブロックされます。キーボードの音声入力キーを使うか、単体版を開いてください。
「このブラウザは音声認識に対応していません」と出る
iPhone は Safari、Android とパソコンは Chrome を使ってください。Firefox は対応していません。
モデルのダウンロードが止まる・失敗する
Wi-Fi につないで再読み込みし、もう一度試してください。途中まで取得した分は次回に引き継がれます。空き容量が約400MBあるかも確認してください。
翻訳が遅い
アプリを開いて最初の翻訳は、モデルをメモリに読み込むので数秒かかります。以後は端末によって1文あたり約1〜5秒です。
「Ollama に接続できません」と出る
パソコンで ollama serve を起動してください。ブラウザが接続を拒否するときは OLLAMA_ORIGINS="*" ollama serve で起動します。Ollama は、それが動いているパソコンからしか使えません。
翻訳の向きが逆になる
AUTO をやめて JA → EN か EN → JA を選んでください。

9. プライバシー

  • In-browser (FuguMT)：翻訳は端末の中で行い、入力した文はどこにも送られません。
  • 音声入力はブラウザの音声認識を使います。Chrome や一部の Safari の設定では、認識のために音声がブラウザ提供元のサーバーに送られます。
  • Ollama はパソコン内だけで動きます。Claude を選ぶと、翻訳のために文が Claude に送られます。
  • 設定と履歴はこのブラウザ内にだけ保存されます。サイトのデータを消去すると消えます。

10. Mac デスクトップ版

voice_translator.py は、完全オフラインで動く Mac 用の別バージョンです。音声認識に Whisper、翻訳に Ollama、読み上げに macOS の say を使います。

  1. ターミナルでアプリのフォルダに移動し、python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt を実行します。
  2. Ollama を起動してから python voice_translator.py を実行します。
  3. 🎤 Record（⌘R）を押して話し、もう一度押すと止まります。訳文が表示され、読み上げられます。
